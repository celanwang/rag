# 数据库设计

首期使用八张业务表。租户短码全局唯一，知识库短码在租户内唯一。CLI 和 API 用短码查找租户和知识库，表间使用 UUID 关联。 [八张表的 SQL](../env/rag/schema.sql#L27)

复合外键约束租户、知识库、文档和版本的归属。业务角色在事务内建立租户上下文，行级安全限制可见行，业务查询再复核知识库权限和文档读权限。API、Worker 和 CLI 的连接搜索路径包含 `rag`，查询可直接使用表名。特权函数固定搜索路径并显式引用业务表。 [角色与权限](../env/rag/schema.sql#L268)

发布只接受持有有效租约且仍指向待发布版本的任务。发布、文档授权变更和删除在更新变更序号的同一事务内入队 ES 同步任务。清理过期版本后，原任务回执和上传幂等键仍可使用。 [版本和任务流程](design.md#上传发布和索引同步)

空库从 `schema.sql` 初始化。启动时读取 `rag` schema 注释中的版本，依序应用增量迁移。v2 和 v3 添加同步与入库的投递保留时间和按 ID 领取函数。v4 添加 ES 代际及每代文档修订检查点。这两张表由重建维护命令访问。 [初始化 SQL](../env/rag/schema.sql) · [增量迁移](../env/rag/migrations)
